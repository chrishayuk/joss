# JOSS "666" listing, J. C. Shaw, 1-9-65 -- every message text stored in the program.
# Source of each text: the packed octal data words (five 8-bit characters per word),
# decoded with the listing's own character table (region A, PDF pp. 7-9), and
# cross-checked against the upper-case comment printed beside each message.

# the relation signs below come from the octal, not from the comments.
