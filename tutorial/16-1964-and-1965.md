# 16. 1964 and 1965

JOSS did not stand still. Shaw changed it while it was in use, and the
pages that survive come from two moments about a year apart: the film of
March 1964 and Shaw's paper of August 1964 on one side, and the pages
typed in April and May 1965 on the other. The language is the same in
both. What JOSS said, and where on the line it typed, is not.

This chapter is about those differences, about how closely this
reconstruction matches the original pages, and about what belongs to the
later JOSS-II and is not here at all.

## The JOSS of 1964

Everything so far has been the JOSS of 1965. A session file can ask for
the earlier one with a line that is not typed at the console:

    ! joss 1964

or the whole file can be run that way with `joss --year 1964`.

```joss
! joss 1964
Type 7/0.
Type sqrt(-1).
Type y.
Type part 2.
Type 2+2, 1/3, .02.
```
```text
Type 7/0.
Error above:  Zero divisor.
Type sqrt(-1).
Error above:  Negative argument for sqrt.
Type y.
Error above:  Undefined.
Type part 2.
Error above:  No such part.
Type 2+2, 1/3, .02.
     2+2 =      4
     1/3 =       .333333333
     .02 =      2·10*(-2)
```

And the same in 1965:

```joss
Type 7/0.
Type sqrt(-1).
Type y.
Type part 2.
Type 2+2, 1/3, .02.
```
```text
Type 7/0.
Error above:  I have a zero divisor.
Type sqrt(-1).
Error above:  I have a negative argument for sqrt.
Type y.
Error above:  y is undefined.
Type part 2.
Error above:  I can't find the required part.
Type 2+2, 1/3, .02.
     2+2 =       4
     1/3 =        .333333333
     .02 =        .02
```

Three things changed.

**The messages became personal.** "Zero divisor." became "I have a zero
divisor.", and "Undefined." became "y is undefined.", which also says
what is undefined. Shaw's account is in
[chapter 12](12-mistakes-and-go.md): it was done "not facetiously, but
rather to reinforce the model" (P-3149, p. 6). A note of Shaw's dated
10 October 1964 has "I need more storage space." worked out by hand in
the machine's character code, so the change was being made that autumn.
In 1964 the same message was "Insufficient storage space." (RM-4162-PR,
p. 37).

**The numbers moved one column to the right.** In the figures of 1964
the units digit of an answer is in the 17th column; on the pages of 1965
it is in the 18th.

**Small numbers kept their decimal point longer.** In the film a value of
.02 is typed as `2·10*(-2)`. By 1965 the rule was the one Shaw states,
fixed point "between .001 and 1,000,000" (P-3149, p. 8).

The interrupt key had other words too. In 1964:

```joss
! joss 1964
1.1 Type x.
! interrupt after 2 lines
Do part 1 for x = 1(1)10.
```
```text
1.1 Type x.
Do part 1 for x = 1(1)10.
       x =      1
       x =      2
Interrupted at step 1.1.
```

In 1965 the same line reads `I'm at step 1.1.`

Only what a page of 1964 shows is known of the 1964 wording: four
messages and the interrupt. For every other message this reconstruction
uses the 1965 words in both years. That is a gap in the evidence, not a
claim that those messages did not change.

## A page from the film

The film was made on 21 March 1964, with F. J. Gruenberger at the
typewriter and C. L. Baker speaking the commentary. Its second problem is
the current in a circuit with resistance, inductance and capacitance
after a charge Q is released: a damped oscillation. Part 1 works out the
constants, the user rounds the interval d to a convenient number by hand,
and part 2 types the table. The film goes on to 100·d; this goes to 20·d.

```joss
! joss 1964
Set k = 2·3.14159265.
1.1 Set F = sqrt[1/(L·C)]/k.
1.2 Set f = sqrt[1/(L·C)-R*2/(4·L*2)]/k.
1.3 Set I = k·F*2·Q/f.
1.4 Set d = .1/f.
1.5 Type F, f, I, d.
Set R = 100.
Set L = .2.
Set C = .5·10*(-6).
Set Q = .001.
Do part 1.
Set d = .0002.
2.1 Type 1000·t, I·exp[-R·t/(2·L)]·sin(k·f·t) in form 3.
Form 3:
```

## How close the reconstruction is

The folder `transcripts/` holds the original pages, typed in from the
scans with a mark on each line to say who typed it. `joss --verify`
replays the user's lines and compares every line JOSS typed with the
page:

```bash
target/release/joss --verify transcripts/*.txt
```

Of more than 750 lines that JOSS typed on those pages, five differ, and
they come down to three numbers, each one unit out in its last digit. All
three are on the pages of 1964, and all three come from the elementary
functions: a logarithm, an exponential and a fractional power. Here those
are worked out to more than nine places and then rounded.

**log 2.** The logarithm of 2 is .69314718056. JOSS typed `.69314718`,
which means its ninth digit was a nought that it then left off: its
log 2 was .693147180, one unit low. Correctly rounded it is .693147181:

```joss
Type log(2).
```
```text
Type log(2).
  log(2) =        .693147181
```

**e to the 72nd.** The film's table has `1.8586717 31` where this has
`1.8586718 31`. The true value is 1.858671745·10*31, so this is a case
where eight figures were asked for and JOSS's ninth, one unit low, tipped
the rounding the other way.

**A long expression.** The film's "Chart A" expression ends in a division
that magnifies the last digit of `2.3*(-.7)`. JOSS had .558200878 for
that power where the true value, .5582008774, rounds to .558200877.

In the transcripts these lines are followed by a line marked `~:` that
gives what the reconstruction types instead, so that the differences stay
in view and the test suite notices if they ever change.

The pages of 1965 replay without a single difference, including the page
of mistakes with its thirteen messages, the matrix inversion and the
formatted table.

## What is supplied

A few things had to be supplied, because no page shows them.

- What a step, a form or a value costs in words of storage
  ([chapter 14](14-storage.md)). The total of 720 words is from the
  sources; the price of each thing is an estimate.
- What JOSS said to `arg(0,0)`, the angle of the origin. Here it says
  "I have arguments of zero for arg.", which is in no listing.

```joss
Type arg(0,0).
```
```text
Type arg(0,0).
Error above:  I have arguments of zero for arg.
```

- The wording of 1964, where no page of 1964 shows a message.

And some of JOSS is not reproduced at all, because it belongs to the
console and not to the language:

- Signing on. JOSS typed "JOSS at your service." and "Initials
  please:", and told a user who had to wait "You are now number n in the
  queue."
- The heading at the top of each page, with the time, the date and the
  user's initials.
- The two colours of the ribbon. (`joss --colour` prints the user's lines
  in green.)
- "Revoked.", which JOSS typed when a direct instruction, not a stored
  program, was interrupted.
- Messages from the operators, such as the one that arrives in the
  middle of figure 2 of P-3149: "Please wind up your work and turn off as
  soon as possible."
- The verbs `Read` and `Punch`, which are in the program listing of
  January 1965 and in none of the papers. They were for keeping programs
  on punched cards. Shaw's paper of May 1965 says that a punched card
  file was rejected "because it would require an operator" (P-3149,
  p. 12), and the one-page summary of JOSS dated 12 January 1965 does
  not list them.

## Before 1964

An older listing of the JOSS program, undated, survives too. Its language
is recognisably the same but some of the words are different: `Erase`
stood beside `Delete`, `Return` did the work of `Line`, and there was no
`Demand`. The functions `dp`, `xp` and `arg` were called `cf`, `sfx` and
`amp`. Its messages are a third wording, more formal than either of the
others: "Attempting division by zero.", "Attempting sqrt of a negative
number." And where JOSS later said "Eh?" it said "Malformed."

None of that is accepted here.

## What is not in JOSS-I

In February 1966 a new JOSS came into service on a PDP-6. It kept the
style of the first and added a good deal to the language. Most
descriptions of "JOSS" are of that one, so it is worth knowing what to
leave out. None of the following is in JOSS-I, and to each of them JOSS-I
says "Eh?":

| JOSS-II | what it was |
|---|---|
| `Let f(x) = x*2.` | formulas: functions defined by the user |
| `sum`, `prod`, `first`, `max[i=1(1)n: ...]` | functions over a range |
| `(x<0: 0; x)` | conditional expressions |
| `true`, `false`, `not`, `tv` | propositions as values |
| `Do part 1, 3 times.` | repetition by count |
| `File`, `Recall`, `Discard`, `Use file` | programs kept from one session to the next |
| `Quit.`, `(Cancel.)`, `(Do part 1.)` | parenthetical commands |
| `Demand x as "text".` | a prompt for a `Demand` |
| `Type timer.`, `Reset timer.` | the timer |

```joss
Let f(x) = x*2.
Type sum(i = 1(1)10: i).
Set y = (1 < 0: 0; 1).
Do part 1, 3 times.
Type x if not 1 = 2.
Quit.
```
```text
Let f(x) = x*2.
Eh?
Type sum(i = 1(1)10: i).
Eh?
Set y = (1 < 0: 0; 1).
Eh?
Do part 1, 3 times.
Eh?
Type x if not 1 = 2.
Eh?
Quit.
Eh?
```

JOSS-I has one answer to "how do I define a function?": make it a part
and `Do` it. To "how do I sum a series?": a step and a `for`. To "how do
I repeat this n times?": `for i = 1(1)n`. To "how do I keep my
program?": on paper.

It is a small language. Its verbs fit on one page, and RAND printed them
on one. The next chapter is that page, with the rest of the reference.
