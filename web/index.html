JOSS

The JOHNNIAC Open-Shop System, RAND, as it stood in 1965: a typewriter, a green ribbon for you and a black one for JOSS. Type a line and press return. A line that begins with a number is kept as a step; anything else is done at once. When something goes wrong, put it right and type Go.

Times is · (type @), and * is “to the power”. Type !=, <=, >= for ≠ ≤ ≥. Every instruction ends with a full stop.
